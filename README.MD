# StickerPatterning

This repository contains simulation data, analysis scripts, and example notebooks used in the paper:

**"Interplay of sticker patterning and spacer energetics affects condensate structure & stability"**

The repository is intended to allow readers to reproduce key analyses presented in the manuscript.

---

# Data availability

Due to repository size limits:

- Only simulations for **uniform** and **patchy** sticker patterns are included.
- Full trajectory **`.dump` files are omitted**.

The repository contains:

- final simulation snapshots (`*.DATA`)
- thermodynamic outputs (`Thermo_*`)
- bond statistics (`BondData_*`)
- analysis scripts
- example notebooks demonstrating figure generation.

Full trajectory data and additional pattern datasets are **available upon request**.

---

# File types in simulation folders

Simulation directories typically contain the following files:

### `final_state_Run{n}.DATA`

Final simulation snapshots used for structural analysis.

These files contain:

- atom coordinates
- molecule IDs
- bond information

---

### `Thermo_*.dat`

Thermodynamic output from the LAMMPS simulations.

These files record:

- **Steps** – Current LAMMPS timestep  
- **Temp** – Instantaneous temperature (K)  
- **KinEng** – Total kinetic energy (kcal mol⁻¹)  
- **PotEng** – Total potential energy  
- **Epair** – Pairwise (non-bonded) energy  
- **Ebond** – Bond energy  
- **Eangle** – Angle energy  
- **Bonds** – Total number of bonds at that step  

---

### `BondData_*`

Tracks bond formation dynamics during the simulation.

These files record:

- total bonds created over time
- total bonds broken over time

They are used to analyze sticker interaction dynamics.

# Repository structure

## `5patterns_clustered_setup/`

Simulation setup files used to generate **clustered initial conditions** for the five canonical sticker patterns studied in the manuscript.

---

## `5patterns_dispersed_setup/`

Simulation setup files used to generate **dispersed initial conditions** for the same set of sequence patterns.

---

## `Clustered_initCond/`

Simulation outputs for runs initialized from **clustered configurations**.

These simulations test whether condensates remain stable when starting from pre-formed clusters.

---

## `Dispersed_initCond/`

Simulation outputs for runs initialized from **dispersed configurations**.

These simulations probe spontaneous condensate formation from homogeneous starting states.

The notebook `cluster_analysis.ipynb` uses data from this directory to compare **uniform** and **patchy** sequences.

---

## `dispersed_phase_L400_intraOnly/`

Simulations where **inter-chain nonspecific interactions are disabled**.

These runs isolate the role of sticker-mediated interactions.

---

## `Reduce_Ens/`

Simulations restarted with **reduced nonspecific interaction strength** \(E_{ns}\).

These runs explore how weakening nonspecific interactions affects condensate formation.

---

## `Rigid_chains/`

Simulations performed with **increased chain stiffness** to test the effect of polymer rigidity on condensate structure.

---

## `SequenceDesign/ZHP_N70_S20_parallel/`

Code used for sequence pattern analysis and sequence design.

Key scripts:

- `PatternMetric.py` – computes dispersion \(H\) and patchiness \(P\)
- `NormMetric.py` – computes normalized metrics \(Z(H)\) and \(Z(P)\)
- `SeqGen_Feasibility_space.py` – Monte Carlo sequence design targeting positions in \(Z(H), Z(P)\) space

---

## `sequence_data/`

Datasets used for sequence pattern analysis.

Includes:

- PLCD sequences
- nuclear IDR datasets
- binary sequence masks used for computing pattern metrics.

---

## `notebooks/`

Example notebooks demonstrating the analyses used in the manuscript.

### `sequence_analysis.ipynb`

Shows how sequence pattern metrics are computed:

- dispersion \(H\)
- patchiness \(P\)
- normalized scores \(Z(H)\) and \(Z(P)\)

---

### `sequence_design.ipynb`

Demonstrates the Monte Carlo sequence design workflow used to generate sequences targeting specific locations in \(Z(H), Z(P)\) space.

---

### `cluster_analysis.ipynb`

Demonstrates structural analysis of simulation outputs.

The notebook reproduces two analyses used in the manuscript:

- intermolecular sticker–sticker distance distributions
- cluster-size distributions

These distributions are **averaged across five replicate simulations** and compared between **uniform** and **patch** sequences.

# Reproducibility

All figures generated by the notebooks can be reproduced directly from the `.DATA` files included in this repository.

Because full trajectory `.dump` files are omitted for size reasons, time-resolved analyses requiring trajectories are not included here but are available upon request.
